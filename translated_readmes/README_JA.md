# myai

myai は、手元のファイルを対象に AI エージェントと作業するためのローカルファーストの AI
ワークスペースです。ワークスペース、スキル、自動化はすべて自分のマシン上に保持されます。

プロダクト、ライセンス、開発フェーズの一次情報は
[`docs/myai-plan.md`](../docs/myai-plan.md) にあります。セットアップ手順を含む完全な
ドキュメントは英語版 README を参照してください: [README.md](../README.md)
