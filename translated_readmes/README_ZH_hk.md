# myai

myai 是一個本地優先的 AI 工作區，讓您用自己的檔案與 AI 代理協作。工作區、技能與自動化
都保存在您自己的機器上。

產品、授權與階段說明以 [`docs/myai-plan.md`](../docs/myai-plan.md) 為準。包含完整安裝
步驟的文件請見英文 README：[README.md](../README.md)
