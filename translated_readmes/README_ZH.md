# myai

myai 是一个本地优先的 AI 工作区，让你用自己的文件与 AI 代理协作。工作区、技能和自动化
都保存在你自己的机器上。

产品、许可证与阶段说明以 [`docs/myai-plan.md`](../docs/myai-plan.md) 为准。包含完整安装
步骤的文档请见英文 README：[README.md](../README.md)
